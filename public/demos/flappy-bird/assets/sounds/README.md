# Audio Assets

Este directorio contiene los archivos de audio del juego:

- `wing.wav` - Sonido cuando el pájaro bate las alas
- `hit.wav` - Sonido cuando el pájaro colisiona
- `point.wav` - Sonido cuando el pájaro pasa un pipe
- `die.wav` - Sonido cuando el juego termina
- `background.mp3` - Música de fondo (opcional)

## Nota
Si estos archivos no están presentes, el sistema de audio generará automáticamente sonidos procedurales como fallback.
